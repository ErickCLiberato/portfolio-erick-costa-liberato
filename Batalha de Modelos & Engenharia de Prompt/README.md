Batalha de Modelos & Engenharia de Prompt

## 📝 Descrição do Projeto

Este trabalho apresenta a **Experiência 3 — Batalha de Modelos & Engenharia de Prompt**, uma atividade acadêmica voltada ao estudo da criação de prompts estruturados em **XML** para geração de uma página **HTML5 Single Page com CSS3 interno**.

O objetivo principal da atividade foi testar o mesmo prompt em diferentes ferramentas de Inteligência Artificial, analisando como cada modelo interpreta instruções estruturadas e gera códigos HTML/CSS a partir de um mesmo comando.

O tema escolhido para a página foi **“A Corrida do Prompt”**, uma atividade educacional sobre Engenharia de Prompt em que grupos competem para criar o melhor comando para Inteligência Artificial em até 5 tentativas.

---

## 🎯 Objetivo da Atividade

Construir um **Prompt Estruturado em XML** capaz de solicitar a criação de uma página web completa, contendo:

- Página HTML5 única;
- CSS3 interno;
- Layout responsivo e minimalista;
- Menu de navegação funcional com âncoras;
- Seção de portfólio ou galeria;
- Rodapé com informações de contato simuladas;
- Estimativa de tokens gerados ao final da resposta.

---

## 🤖 Modelos de IA Comparados

Durante a atividade, o prompt foi testado em diferentes modelos de Inteligência Artificial, incluindo:

- ChatGPT
- Gemini
- DeepSeek
- Qwen
- Grok
- Maritaca
- Claude

A comparação foi feita com base em critérios como:

- Precisão estimada do resultado;
- Precisão do HTML;
- Criatividade no conteúdo;
- Erros de sintaxe ou bugs;
- Quantidade aproximada de tokens gerados.

---

## 🧩 Estrutura do Prompt XML

O prompt utilizado foi organizado com tags XML para deixar as instruções mais claras e separadas por categorias, como:

```xml
<tarefa>
  <objetivo>Criar uma página HTML5 única com CSS3 interno.</objetivo>
  <tema>A Corrida do Prompt</tema>
  <diretrizes_design>
    <layout>Responsivo, moderno e minimalista.</layout>
    <paleta_cores>Azul-marinho, preto suave, roxo, azul e ciano.</paleta_cores>
    <tipografia>Sans-serif para títulos e serif para corpo.</tipografia>
  </diretrizes_design>
  <obrigatoriedades_tecnicas>
    <item>Menu de navegação funcional.</item>
    <item>Seção de galeria ou portfólio.</item>
    <item>Rodapé com contato simulado.</item>
    <item>Design responsivo para diferentes telas.</item>
  </obrigatoriedades_tecnicas>
</tarefa>
