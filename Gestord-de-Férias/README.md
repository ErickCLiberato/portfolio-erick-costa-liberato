# 💰 Gestor de Orçamento

> Site desenvolvido para auxiliar no controle de orçamento pessoal, permitindo organizar receitas, despesas e acompanhar melhor a situação financeira.

---

## 📝 Descrição do Projeto

O **Gestor de Orçamento** é uma aplicação web criada com o objetivo de facilitar o acompanhamento financeiro do usuário de forma simples, visual e prática.

A proposta do projeto é permitir que o usuário tenha uma visão mais clara sobre seu orçamento, registrando valores, analisando gastos e organizando melhor sua vida financeira. A aplicação foi desenvolvida utilizando a plataforma **Bubble**, com foco em criação visual, prototipagem rápida e construção de soluções web sem a necessidade de programação tradicional.

Este projeto demonstra a aplicação de conceitos de **desenvolvimento no-code**, organização de interface, experiência do usuário e lógica de funcionamento para sistemas de controle financeiro.

## 🚀 Tecnologias Utilizadas

* **Plataforma:** Bubble.io
* **Tipo de desenvolvimento:** No-Code / Low-Code
* **Interface:** Editor visual do Bubble
* **Banco de dados:** Banco interno do Bubble
* **Hospedagem:** Bubble Cloud
* **Ferramentas de apoio:** GitHub, IA generativa e documentação em Markdown

---

## ⚙️ Funcionalidades

* Registro de valores relacionados ao orçamento.
* Organização de receitas e despesas.
* Visualização do saldo ou resultado financeiro.
* Interface simples e intuitiva.
* Estrutura pensada para uso pessoal e controle financeiro básico.
* Possibilidade de expansão para novas funcionalidades, como categorias, gráficos e relatórios.
